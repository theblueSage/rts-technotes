# Right Take Studio — Tech Notes

Open documentation of how [Right Take Studio](https://righttakestudio.com)
(Boston, MA) technically works: the signal chain, the gear, and the methodology
behind a live-recorded, multi-camera, streamed session.

These are the shareable *"so how the hell do we technically make this happen?"*
notes. Per-band **operational** settings (channel maps, device IPs, session
templates) are kept private and are **not** part of this repo.

This repo is rendered inside the studio site at
<https://righttakestudio.com/docs/> — it's pulled in as a **git submodule**.
It's also just Markdown: clone it and read.

## Layout

- `overview/` — the high-level tour of the pipeline
- `gear/` — how each device works (M32, RME TotalMix, PTZOptics, OBS, Pro Tools …)
- `CONVENTIONS.md` — file naming + frontmatter schema
