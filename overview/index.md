A plain-language tour of the studio's signal and production chain — the page a
curious visitor (or a new engineer) reads first. Deep settings live in the
gear guides.

## Signal path (high level)

1. **Instruments / mics** → stage **snake** inputs.
2. **Preamps / head amps** set gain, phantom power, and polarity.
3. **M32** digital desk — EQ, dynamics, de-esser, phase, routing, FX. Each band
   is recalled as an **M32 Scene** (see
   [M32-Edit Scenes](/docs/gear/m32/scenes-band-config/)).
4. **IEM** monitoring via **M32C**, per-musician mixes controlled from a phone.
5. **Capture** — **Pro Tools** multitrack + **RME TotalMix FX** routing.
6. **Video** — **PTZOptics** cameras → **OBS** → restream to the platforms.

## How these notes are organized

- **Band** is the primary key; **Song** is the level below it.
- Hardware settings are captured as **numbers + a proof photo**, with the values
  transcribed into each page's frontmatter.
- Shareable methodology lives here (public). Per-band operational settings stay
  private.
